Exercício 01 — Box Model

Crie um <div> com width: 300px, padding: 20px, border: 3px solid red e margin: 40px.
Compare o tamanho final usando box-sizing: content-box versus border-box. Use as DevTools do browser (F12) para inspecionar.

content-box: 300px + 40px padding + 6px border = 346px no layout

border-box: 300px total (padding e border incluídos)
